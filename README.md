# 염원 SV 아카데미 랜딩페이지

프랜차이즈 본사 대상 교육 상담용 광고 랜딩페이지 (염원컴퍼니)

- 과정: SV 실무 교육 · 가맹점 AI 마케팅 교육 · 가맹점주 온라인 교육
- 구성: 단일 `index.html` (이미지 포함), 별도 빌드 없음
- 배포: Netlify (저장소 루트 그대로 배포)

## 상담 신청 접수 (Netlify Forms)

페이지의 두 상담 폼은 Netlify Forms로 접수됩니다.

| 폼 이름 | 위치 | 항목 |
|---|---|---|
| `consult-main` | 페이지 하단 상담 영역 | 본사명, 담당자, 연락처, SV 인원, 관심 방식, 문의 내용 |
| `consult-bar` | 하단 고정 상담 바 | 본사명, 담당자, 연락처, SV 인원, 개인정보 동의 |

Netlify 관리 화면 → Forms 에서 신청 내역을 확인하고, Form notifications 에서 이메일 알림을 설정합니다.

## 수정 방법

`index.html` 을 수정해 main 브랜치에 올리면 Netlify가 자동으로 다시 배포합니다.
